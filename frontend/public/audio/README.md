# Worship Music

Drop your worship/instrumental MP3 file here as **`worship.mp3`**:

```
/app/frontend/public/audio/worship.mp3
```

After adding the file:
1. Click **"Save to Github"** in the chat to push it
2. The GitHub Actions workflow will deploy it automatically
3. The 🎵 button in the bottom-left of every page will play it on loop at 25% volume

**Tips for picking a track:**
- Keep it under 5 MB so it loads fast on mobile
- Pick a soft, looping instrumental (piano/strings/pad) so the loop is seamless
- Make sure you have the license to use it on a public site

**Free / royalty-free sources to consider:**
- pixabay.com/music (free for commercial use)
- freemusicarchive.org → search "worship", "ambient christian", "hymn instrumental"
- yourpublicdomainsource.com
- Or record your own quiet piano hymn :)

Until a file is uploaded, the button will gracefully show "Worship music is coming soon" when tapped.
